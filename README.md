# Turkey Squares

Live tracker for the 2026 Thanksgiving Day football squares pool (Bears at Lions, Eagles at Cowboys, Chiefs at Bills).

- Pulls live scores from ESPN every 20 seconds and fills in each quarter's payout score automatically (the final includes OT).
- Shows who wins if the quarter ended now, and what has to happen for your squares to hit. Everyone picks their own name, so one link works for the whole pool.
- Manual mode for entering scores by hand if the feed is down.

Open it on your phone and use **Share → Add to Home Screen** to install it like an app.
